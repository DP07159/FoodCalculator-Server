# Food Calculator – Sprint 0

Dieser Stand ergänzt ausschließlich die technische Migrationsgrundlage. Bestehende V1-Routen und Fachfunktionen bleiben erhalten.

## Befehle

- `npm install`
- `npm run smoke`
- `npm run migrate`
- `npm run backup`
- `npm run restore:test -- backups/<datei>.sqlite`
- `npm start`

Die lokale Standarddatenbank liegt unter `data/food_calculator.sqlite`. Auf Render wird weiterhin `/var/data/food_calculator.sqlite` verwendet.
